# Задача: новинки Bot API 10.4 (9 ноября 2026) для наших ботов

Источник: [журнал изменений Bot API, 9 ноября 2026](https://core.telegram.org/bots/api-changelog#november-9-2026). Разбор сделал поисковик 10.11.2026 пересказом страницы, поэтому формулировки сверять с оригиналом. Бот — [[11 Бот базы знаний]]. Владимир тестирует новые опции вечером 10.11.2026.

## Что берём

1. **Эфемерные сообщения** (главное). Ответ на нажатие кнопки в любом чате, кроме прямых чатов канала, виден только нажавшему: в `ephemeral_message_parameters` указывается `callback_query_id` без `receiver_user_id`; `chat_id` стал необязательным. Применение в боте: чек-лист задач и утренняя сводка в общем чате «Деньги & Право» — подтверждения («☑ отмечено»), детали задачи, отказ «отмечать могут только участники» показывать только нажавшему, не засоряя ленту.
2. **HTML-виджеты** (`sendWidget`, `answerWidgetQuery`, `editMessageWidgetData`). В продакшене только в личных чатах, inline-вариант пока не работает. Кандидат: лёгкая замена странице `/lk` (лизинговые компании) без отдельного хостинга. Для Батлера (семья) — интерактивный список платежей вместо кнопок.
3. **Ссылки на темы в личных чатах с ботом** (`t.me/<бот>/<id темы>`): в напоминаниях вести сразу в нужную тему. Сначала проверить, есть ли у нас темы в личке с ботом.
4. **`bank_card_number` в MessageEntity**: если в сообщении номер карты, бот предупреждает и не пишет его в базу (правило безопасности: данные карт не храним). Касается обоих ботов, Батлера и бота базы знаний.

Остальное (TON, подарки, темы шаринга, вторичные юзернеймы ботов, цитаты rich-сообщений) нам не нужно.
