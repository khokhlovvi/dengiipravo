# Задача: публикация в общий чат по запросу участника

Разбор 27.11.2026 по ситуации с Адамом. [[Мараев Адам Хож-Ахмедович|Адам]] попросил бота опубликовать информацию в общий чат (тема General), но бот отказал: такого сценария нет. Разобрали по документации хранилища и README бота на сервере, как публикация устроена сейчас и что добавить. Бот — [[11 Бот базы знаний]].

## Главное

Бот умеет публиковать в общий чат, но только через закреплённые сценарии; произвольного сообщения по просьбе участника нет — это по замыслу, а не поломка. Предложение: добавить сценарий «черновик + кнопка», как у минуток, — участник просит в личке, бот показывает текст и публикует только по кнопке.

## Как публикация устроена сейчас

| Сценарий | Как запускается | Куда |
|---|---|---|
| Минутка встречи с чек-листом задач | Кнопка «📣 Опубликовать в общем чате» под ответом бота в личке; нажать может только участник | Тема «Задачи и минутки летучек» |
| CVR по клиенту | Только по кнопке и только кратким анонсом; полный CVR в чат не уходит | Общий чат |
| Утренняя сводка открытых задач | Автоматически в 09:05 (digest.py) | Тема «Задачи и минутки летучек» |
| Итоги недели | Автоматически по воскресеньям в 17:00 (dip-weekly-summary) | Тема General |
| Новостной дайджест | Автоматически ежедневно в 08:00 (news-parser) | Тема «Новости» |
| Произвольный текст по просьбе участника | Нет такого сценария | — |

В самом общем чате бот молчит и в разговоры не вступает. Исключение из практики: файл по ФРиО в ноябре 2026 отправлен в чат по просьбе Владимира — делалось через сервер, а не через сценарий бота.

## Что добавить

1. **Черновик публикации.** Участник пишет в личке «опубликуй в общий чат: …». Бот причёсывает текст до короткого анонса, показывает черновик и спрашивает, в какую тему (по умолчанию — General).
2. **Кнопка «📣 Опубликовать»** под черновиком. Нажать может только участник проекта; до нажатия ничего не уходит. Механика — как у минуток (boards.json).
3. **Отметка об авторе.** В сообщении в чате — пометка, кто инициировал публикацию, чтобы чат видел, от кого информация.
4. **Уведомление Владимиру** в личку о каждой такой публикации — тот же канал, что NOTIFY_WRITES.
5. **Справка бота (/help) и [[Памятка о боте для команды]]**: дописать сценарий.
