# Задача: какие файлы понимает бот базы знаний и что добавить

Разбор 11.11.2026 по вопросу Владимира. Смотрели код бота на сервере (`~/automations/dip-bot/bot.py`) и его разговоры с участниками, проверяли тестовыми файлами на сервере. Бот — [[11 Бот базы знаний]].

## Главное

Word, Excel и PowerPoint бот принимает и кладёт в `91 Исходники/Из Telegram/`, но прочитать не может. Claude в боте открывает только текст, картинки и PDF, офисные файлы для него закрыты. 11.11.2026 [[Мараев Адам Хож-Ахмедович|Адам]] прислал «Партнеры ЛК (1).xlsx» и попросил разобрать файл, чтобы заполнить таблицу. Бот ответил, что открыть его не может, и попросил прислать CSV, текст или скриншот. Тестовый docx на сервере дал ту же ошибку.

## Что бот понимает сейчас

| Что присылают | Что происходит |
|---|---|
| Текст, голосовое, кружок | Понимает, голос расшифровывается на сервере |
| Аудио и видео файлом (m4a, mp3, wav, mp4, mov и другие) | Расшифровывает речь, длинную расшифровку сохраняет в [[12 Встречи]] |
| Обычное видео из галереи | Не замечает: читает только подпись, а без подписи молчит |
| Фото, скан, скриншот | Понимает, Claude видит картинку |
| Картинка файлом: JPG, PNG, WebP | Понимает |
| Картинка HEIC (формат фото айфона, приходит, если отправить фото файлом) | Не откроет: Claude такой формат не читает |
| PDF, в том числе сканы | Понимает. Проверено на 12 страницах и на договоре РапидаТех в 19 МБ. Не прочитает только очень длинный документ, примерно от сотни страниц: такие читаются по частям, а для этого на сервере нужна утилита poppler, её нет |
| TXT, MD, CSV | Понимает |
| Word, Excel, PowerPoint (docx, doc, xlsx, xls, pptx) | Сохраняет, но не читает |
| RTF, ODT, ODS | Не читает. RTF формально текстовый, но русские буквы в нём закодированы |
| Архивы ZIP, RAR, 7Z | Не читает |
| Письма EML, MSG | Не читает: русский текст и вложения внутри письма закодированы |
| HTML, JSON, XML, VCF, ICS | Читает как текст. Файл лежит во временной папке `.inbox/` и через 7 дней удаляется |
| Контакт из Telegram, геопозиция | Молча пропускает |
| Несколько файлов одним сообщением | Каждый файл разбирает отдельным запросом и отвечает отдельно. Подпись с задачей есть только у первого файла, поэтому просьба «сравни эти договоры» не сработает |
| Пересланное сообщение | Текст читает, но не знает, от кого оно, и считает, что это сказал сам участник |
| Файл больше 20 МБ | Telegram не отдаёт ботам такие файлы |

## Что добавить

### Первая очередь: починить обещанное

1. **Word, Excel, PowerPoint, в том числе старые doc и xls.** Бот сам переводит файл в текст до того, как отдать его Claude: документ — текстом с таблицами, Excel — каждый лист таблицей, презентацию — текстом слайдов и заметками докладчика. Тогда просьбы вроде Адамовой «разбери таблицу, чтобы я её заполнил» и «сверь таблицу с карточками» начнут работать.
2. **HEIC.** Бот переводит картинку в JPG.
3. **Обычное видео.** Расшифровывать речь, как у кружков и видеофайлов.
4. **Очень длинные PDF.** Поставить на сервер poppler, это небольшой пакет. Claude сможет читать PDF по частям.
5. **Справка бота** (`/help`) и [[11 Бот базы знаний]]: перечислить, какие файлы бот понимает.

### Вторая очередь: новое

6. **RTF, ODT, ODS.** В RTF часто сохраняют документы из правовых баз (КонсультантПлюс, Гарант). ODT и ODS — форматы МойОфиса и LibreOffice, встречаются на госсайтах.
7. **Архивы ZIP, RAR, 7Z.** Пачка документов одним файлом: материалы дела, документы клиента, тендер. Бот распаковывает архив, читает каждый файл и пишет одну выжимку на всё. Учесть русские имена файлов в архивах из Windows, у них своя кодировка.
8. **Несколько файлов одним сообщением.** Собирать их вместе и разбирать одним запросом, с общей подписью.
9. **Контакт из Telegram.** «Поделиться контактом» — и бот заводит карточку человека в [[03 Люди и компании]] или дописывает уже существующую.
10. **Пересланные сообщения.** Передавать Claude, от кого и когда переслано, чтобы факт записался за настоящим автором. В журнале общего чата это уже сделано (`chatlog.py`), можно взять оттуда.
11. **Excel на выход.** По просьбе бот присылает таблицу из базы: лизинговые компании, партнёры, задачи. Вместе с пунктом 1 получается круг: Адам получил таблицу, заполнил, прислал обратно, а бот разнёс данные по карточкам раздела [[14 Лизинг и коммерческая недвижимость]].

### Можно позже

- Письма EML и MSG (Outlook) с вложениями — пересланная переписка с партнёрами.
- На выход: VCF (контакт из базы одним нажатием сохраняется в телефон) и ICS (встреча или срок задачи — в календарь).
- Электронные подписи SIG и P7S к документам из ФНС и Госуслуг: хранить рядом с документом и показывать, кто подписал.
- Файлы больше 20 МБ. Свой сервер Bot API поднимает предел до 2 ГБ, но это ещё одна постоянная служба на сервере. Пока хватает обходных путей из [[11 Бот базы знаний]]: голосовое вместо файла, запись частями, большой файл — через Claude на Маке.

Не берём: презентации на выход (их делаем на Маке), электронные книги, разбор кадров из видео.

## Как сделать

- Перевод в текст делает код бота до вызова модели, как уже сделано с голосовыми. Claude в боте остаётся с прежними инструментами, без команд на сервере (так безопаснее), а резервный Kimi получает тот же текст.
- Для форматов, которые Claude сам не читает, бот кладёт текстовую копию рядом с оригиналом в `91 Исходники/Из Telegram/` (то же имя с `.txt` в конце). По ней работает поиск и бота, и Claude на Маке, и к документу можно вернуться позже без повторной пересылки. Важное, как и сейчас, Claude записывает в базу выжимкой.
- Инструменты лёгкие, без LibreOffice, чтобы хватило памяти сервера (2 ГБ): python-docx, openpyxl и python-pptx (или markitdown) для Office, catdoc для старых doc и xls, pandoc для ODT, striprtf или unrtf для RTF, poppler-utils для PDF, pillow-heif для HEIC, стандартный Python и unar для архивов. Окончательно подобрать и проверить при установке.
- Перед правкой — копия `bot.py.bak-ГГГГ-ММ-ДД`, как при прошлых доработках. После — проверка тестовым файлом каждого формата и запись в README бота.
