# 03 Люди и компании

По карточке на человека и компанию. История дописывается в конец карточки блоком с датой.

## Люди

```dataview
TABLE WITHOUT ID file.link AS "Человек", relation AS "Кто", company AS "Компания", status AS "Статус"
FROM "03 Люди и компании" WHERE type = "person" SORT file.name
```

## Компании

```dataview
TABLE WITHOUT ID file.link AS "Компания", relation AS "Кто нам", site AS "Сайт"
FROM "03 Люди и компании" WHERE type = "company" SORT file.name
```
