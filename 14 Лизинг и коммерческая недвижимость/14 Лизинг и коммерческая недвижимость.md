# 14 Лизинг и коммерческая недвижимость

Отдельная часть бизнеса внутри «Деньги и Право»: агентские отношения с лизинговыми компаниями и сеть брокеров коммерческой недвижимости. Ведёт [[Мараев Адам Хож-Ахмедович|Адам]].

Рабочий инструмент — страница «Лизинговые компании» (https://khokhlovvi.github.io/dip-lk/): стратегия с ходом к целям года (Адам дополняет её прямо оттуда), карточки ЛК, подбор ЛК под клиента, брокеры и дорожная карта. Открывается из бота базы знаний командой `/lk` или кнопкой «ЛК» в меню чата; в браузере — по личной ссылке из того же `/lk`. Правки из инструмента сразу попадают в эти заметки, а всё, что написано боту текстом, видно в инструменте.

## Лизинговые компании

```dataview
TABLE WITHOUT ID file.link AS "ЛК", readiness AS "Группа", stage AS "Этап", agreement AS "Договор", realty AS "Недвижимость", av AS "АВ, %", last_contact AS "Контакт"
FROM "14 Лизинг и коммерческая недвижимость/Лизинговые компании"
WHERE relation = "лизинговая компания"
SORT file.name
```

## Ход

```dataview
TABLE WITHOUT ID key AS "Этап", length(rows) AS "ЛК"
FROM "14 Лизинг и коммерческая недвижимость/Лизинговые компании"
GROUP BY stage
```
