# Брокеры коммерческой недвижимости

Список брокеров и агентств коммерческой недвижимости, с которыми Адам выстраивает отношения. На каждого — карточка по шаблону «Брокер» в этой папке. Пока никого нет: этап 3 [[Дорожная карта Адама|дорожной карты]].

```dataview
TABLE WITHOUT ID file.link AS "Брокер", city AS "Город", segment AS "Объекты", stage AS "Этап", last_contact AS "Последний контакт"
FROM "14 Лизинг и коммерческая недвижимость/Брокеры"
WHERE relation = "брокер коммерческой недвижимости"
SORT last_contact DESC
```
