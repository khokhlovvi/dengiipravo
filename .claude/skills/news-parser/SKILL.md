# Парсер новостей «Деньги и Право»

Ежедневно в 08:00 (МСК) автоматизация `news-parser` на сервере собирает новости суток, модель отбирает топ-20 и пишет выжимки. Результат: заметка `15 Новости/ГГГГ-ММ-ДД.md` в хранилище (приезжает на Мак через git-синхронизацию) и сжатая версия в теме «Новости» общего чата «Деньги & Право».

## Как устроено

1. Конфиг читается из хранилища: `15 Новости/Источники и темы.md`, блок ` ```json ` (темы с ключевыми словами, RSS-источники, `top_n`, `window_hours`, `max_candidates`).
2. Сбор RSS-лент (stdlib, параллельно), дедупликация по базе `seen.db` (хеши заголовков и ссылок, 30 дней), предфильтр ключевыми словами → до `max_candidates` кандидатов. Токены не тратятся.
3. **Оценка — haiku**: один вызов, кандидаты (заголовок + сниппет) → JSON с оценкой 0–10, темой и сутью одной строкой; берётся топ-`top_n`.
4. Для топ-20 скачиваются полные тексты статей (где лента их не отдаёт; ссылки Google News не скачиваются — по ним работаем по сниппету).
5. **Дайджест — sonnet**: один вызов, топ-20 с текстами → markdown по шаблону «90 Шаблоны/Дайджест новостей.md».
6. Заметка пишется в `~/vaults/dengiipravo/15 Новости/ГГГГ-ММ-ДД.md`, коммит «Новости (бот): дайджест ГГГГ-ММ-ДД», push.
7. Telegram: в тему «Новости» (thread id в `~/automations/news-parser/.env`, `NEWS_THREAD_ID`) уходит короткий анонс — дата, число новостей, список тем и ссылка на приложение (без текста новостей — решение Владимира 2026-11-15: стимул заходить в приложение и оценивать); chat id группы берётся из `boards.json` dip-bot.

## Обратная связь (👍/👎) — Mini App

У сообщения дайджеста в чате — кнопка «📰 Открыть дайджест и оценить»: открывает HTML-приложение (Mini App) с дайджестом по темам, полными выжимками и голосованием 👍/👎 у каждой новости (повторное нажатие снимает оценку, счётчики видны сразу). Голоса пишутся в `feedback.db` (45 дней истории учитывается). При следующем запуске сводка оценок подмешивается в промпт скоринга: похожие на 👎 новости получают оценку ≤ 4 и не попадают в дайджест, похожие на 👍 — приоритет. Живая сводка — заметка `15 Новости/Оценки участников.md` (обновляется при новых голосах). Последние оценки: `ssh server '~/automations/news-parser/news.py stats'`.

Устройство приложения: страница — `/var/www/dip-news/index.html` (один файл, `https://dengiipravo.ru/news-app/`), API — `~/automations/news-parser/api.py` (служба `news-api.service`, 127.0.0.1:8791, снаружи `https://dengiipravo.ru/news-api/` через Caddy). Дайджесты для страницы — `digests/ГГГГ-ММ-ДД.json` (пишет `news.py run`; переотправить день из заметки: `news.py resend ГГГГ-ММ-ДД`). Голосование — только участникам: подпись Telegram initData токеном бота (как у инструмента ЛК); без initData страница — в режиме чтения.

Нюанс: web_app-кнопки в группах Telegram запрещены, поэтому в чате — URL-кнопка. Пока она ведёт на `NEWS_APP_URL` (страница открывается во встроенном браузере, голосование выключено). Чтобы страница открывалась как Mini App с голосованием прямо в Telegram: Владимир в @BotFather делает `/newapp` для @DIP_knowledge_base_bot (короткое имя `news`, url https://dengiipravo.ru/news-app/), затем в `~/automations/news-parser/.env` раскомментировать `NEWS_APP_TG=https://t.me/DIP_knowledge_base_bot/news`.

Оптимум по токенам: механический предфильтр (0 токенов) отсекает ~90% ленты, дешёвый haiku оценивает кандидатов по сниппетам, дорогой sonnet пишет только финальный текст по топ-20. Оба вызова — через `~/automations/_ai` (Claude по подписке, при режиме `auto` — резерв Kimi, инструменты не даются, `tools=[]`).

## Типовые задачи

**Запустить дайджест вручную прямо сейчас:**
```
ssh server '~/automations/news-parser/news.py run'
```
Смотрит только ещё не показанные новости. Прогон без записи и отправки (показать, что вышло бы): `news.py run --dry`. Игнорировать «уже показано» (пересобрать за окно заново): `news.py run --fresh`.

**Добавить/убрать источник или тему:** править `15 Новости/Источники и темы.md` (JSON-блок) — изменения применяются со следующего запуска, на сервере ничего менять не нужно. Новый RSS перед добавлением проверить: `ssh server 'curl -sL -o /dev/null -w "%{http_code}" -m 12 -A "Mozilla/5.0" <url>'`.

**Обработать итоги опроса об источниках:** голоса смотреть в теме «Новости», свои варианты участники пишут комментариями. Проверенные RSS добавить в `sources`, зафиксировать в заметке дату и итоги опроса.

**Поменять время запуска:** `ssh server`, в `~/.config/systemd/user/news-parser.timer` поправить `OnCalendar`, затем `systemctl --user daemon-reload && systemctl --user restart news-parser.timer`.

**Поменять топ-N или глубину окна:** поля `top_n`, `window_hours` в конфиге.

**Диагностика:** лог — `ssh server 'tail -30 ~/automations/news-parser/log.txt'`; журнал службы — `ssh server 'journalctl --user -u news-parser -n 50'`. Дайджест не пришёл: смотреть лог; при сбое Claude сработает резерв Kimi (режим `auto`), при лежащем ВПН сервера лента Рунета всё равно доступна. Очистить память показанного: удалить `~/automations/news-parser/seen.db` (следующий прогон покажет всё за окно заново).

**Тема для отправки сменилась:** узнать id новой темы — `ssh server '~/automations/news-parser/news.py topics'` (показывает известные темы группы из журнала чата dip-bot), записать в `~/automations/news-parser/.env` как `NEWS_THREAD_ID=<id>`.
