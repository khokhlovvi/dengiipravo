# 91 Исходники

Копии исходных файлов Владимира. Оригиналы — у него в Документах, их не трогаем, здесь только читаем.

Разобранный файл получает заметку-выжимку (шаблон «Выжимка документа») в разделе по теме.

## Выжимки

```dataview
TABLE WITHOUT ID file.link AS "Выжимка", source AS "Файл", file.folder AS "Раздел"
WHERE type = "source" SORT file.mtime DESC
```
