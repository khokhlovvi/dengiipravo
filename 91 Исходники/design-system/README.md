# Apple Design для проекта

Установлен набор [s1gmamale1/apple-design-skills](https://github.com/s1gmamale1/apple-design-skills), выбранный из предоставленной подборки GitHub. Это 9 навыков с рекомендациями и примерами для проектирования интерфейсов, а не готовый npm-пакет компонентов или официальный продукт Apple.

## Расположение

- На компьютере: `/Users/admin/.codex/skills/apple-design` и восемь соседних папок `apple-design-*`.
- Переносимая копия в проекте: `apple-design-skills/skills/`.
- Версия: `8a3fbea8b561405e5719d682ebd1d14c952aecd7`, установлена 12 сентября 2026 года.
- Лицензия MIT сохранена в `apple-design-skills/LICENSE` и в глобальных папках навыков.
- Перечень модулей и источник: `apple-design-skills/installation.json`.

## Применение

Начать с `apple-design-skills/skills/apple-design/SKILL.md`. Набор охватывает основы дизайна, материалы, движение, веб-интерфейсы, взаимодействия, платформы Apple, доставку контента и доступность. Для новых интерфейсов проекта использование набора закреплено в корневом `AGENTS.md`.

Пример запроса: «Создай интерфейс проекта “Деньги и Право”, используя apple-design».

Набор не требует установки Node.js, Flutter или дополнительных приложений. Зависимости конкретного интерфейса будут определены при его реализации. Обновление выполнять явно с фиксацией новой версии; локальная копия сама не обновляется.

## Официальные источники Apple

- [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)
- [Apple Design Resources — официальные UI kits и шаблоны](https://developer.apple.com/design/resources/)
- [Шрифты Apple](https://developer.apple.com/fonts/)
- [SF Symbols](https://developer.apple.com/sf-symbols/)

Официальные UI kits, файлы шрифтов и SF Symbols в эту установку не входят. Рекомендации автора, отмеченные inferred/speculative, являются интерпретациями.
