# Первая версия сайта — архив

Сайт dengiipravo.ru в том виде, в каком он работал с 26.10 по 10.11.2026 (до региональной версии). Исходники — состояние git-коммита `ac4b343` (тег `site-v1`), без скриншотов `qa/` и исходных PNG `images-src/` (готовые картинки есть в `public/images/`).

## Как вернуть

Быстро, готовыми файлами (сборка лежит на сервере):

```
ssh server 'rsync -a --delete ~/automations/dengiipravo-site/backup-2026-11-10/ /var/www/dengiipravo/'
```

Сборкой из этих исходников:

```
export PATH=$HOME/.local/node/bin:$PATH
rsync -a --delete --exclude node_modules --exclude dist "91 Исходники/site-archive-v1/" /tmp/dip-build-v1/
cd /tmp/dip-build-v1 && npm install && npm run build
rsync -az --delete /tmp/dip-build-v1/dist/client/ server:/var/www/dengiipravo/
```

Caddy менять не нужно. Прежний конфиг с тестовой версией `/test/` — `/etc/caddy/Caddyfile.bak-2026-11-10`.
