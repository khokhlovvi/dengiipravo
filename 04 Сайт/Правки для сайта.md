# Правки для сайта

Идеи и пожелания по доработке [[Сайт|сайта]]. Сделанное отмечаем и переносим в «Сайт».

## Идеи

- Эффекты из рилса (Михаил, @mike.mozg, 2026-10-25, https://www.instagram.com/reel/De64a1pTIhi/), добавлено 2026-10-26. Четыре GitHub-репозитория, код под которые, по словам автора, пишет Claude Code. Названия взяты из расшифровки речи, ссылок в ролике нет, автор высылает их за комментарий «290» — уточнить на GitHub:
  - React Three Fiber — настоящая 3D-графика, например предмет, который крутят мышкой.
  - Liquid Glass React — стеклянные кнопки и карточки в стиле Apple. В Safari и Firefox преломление почти не видно.
  - Shader Gradient — живой градиент на фоне, но тянет 3D-движок и утяжеляет страницу.
  - Liquid Logo — плоский логотип в переливающемся жидком металле.
  - К проверке: не пойдёт ли это вразрез с правилами проекта — спокойная анимация, читаемость, скорость загрузки.
