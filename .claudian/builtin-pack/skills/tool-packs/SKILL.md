# Наборы инструментов

Набор — папка `.claudian/packs/<имя>/` в корне хранилища, в формате плагина
Claude Code. Плагин подключает все наборы оттуда сам; ничего в `~/.claude` не
прописывать, `claude mcp add` не вызывать.

## Состав

```
<имя>/
  .claude-plugin/plugin.json   обязателен: {"name": "<имя>", "version": "1.0.0", "description": "..."}
  .mcp.json                    MCP-серверы: {"mcpServers": {"<сервер>": {...}}}
  skills/<навык>/SKILL.md      навыки: frontmatter name + description, дальше инструкция
  agents/<агент>.md            агенты: frontmatter name, description, tools
  commands/<команда>.md        команды
  server.js, *.py ...          код MCP-сервера
  .state/                      рабочее состояние: сессии, кеши, логи
```

- `name` в plugin.json совпадает с именем папки: латиница, цифры, `-`, `_`, `.`.
- Агенту навык виден как `<имя>:<навык>`, MCP-инструменты — как
  `mcp__plugin_<имя>_<сервер>__<инструмент>`.

## Пути и ключи

- Путь к файлам набора в `.mcp.json` — только через `${CLAUDE_PLUGIN_ROOT}`:
  `{"command": "node", "args": ["${CLAUDE_PLUGIN_ROOT}/server.js"]}`. Абсолютных
  путей не писать — у другого человека набор лежит в другом месте.
- Ключи, токены, пароли в файлы набора НЕ писать никогда. В `.mcp.json` —
  переменная: `"headers": {"Authorization": "Bearer ${PLANER_TOKEN}"}` или
  `"env": {"TG_API_HASH": "${TG_API_HASH}"}`. Человек задаёт значение сам:
  Настройки → Claude → «Наборы инструментов» → ключ из хранилища секретов
  Obsidian. Значение по умолчанию — `${VAR:-значение}`, такую переменную у
  человека не спрашивают.
- Всё, что инструмент пишет во время работы (сессии Telegram, куки браузера,
  кеши, логи), — в `${CLAUDE_PLUGIN_ROOT}/.state/`. Эта папка не уходит в архив
  при передаче набора и не заставляет плагин перечитывать набор.

## Зависимости

- Предпочитать то, что не надо ставить: `npx -y <пакет>`, `uvx <пакет>`, Node
  без пакетов, Python из стандартной библиотеки.
- Если пакеты нужны — `package.json` / `requirements.txt` в наборе и установка
  внутрь набора (`node_modules/`, `.venv/`). Эти папки в архив не идут: в
  описании набора (README.md) написать, какой командой их поставить.

## Когда правка вступает в силу

Со следующего сообщения человека: правку внутри набора плагин перечитывает
без перезапуска, новый набор подключает перезапуском между ходами — разговор
сохраняется. В текущем ходе новые инструменты ещё не видны — сказать человеку,
что проверить можно следующим сообщением.

## Проверка перед тем, как сказать «готово»

1. plugin.json и .mcp.json — валидный JSON (`node -e "JSON.parse(require('fs').readFileSync(process.argv[1],'utf8'))" <файл>`).
2. MCP-сервер запускается руками из папки набора и не падает сразу.
3. Ни одного ключа в файлах набора: `grep -rniE "token|secret|password|api[_-]?key" <набор>`
   — найденное должно быть только именами переменных.
4. Сказать человеку, какие ключи задать и где.

## Передача

Настройки → Claude → «Наборы инструментов» → кнопка выгрузки набора: плагин
соберёт zip без зависимостей, `.state/` и файлов, похожих на ключи. Получатель
ставит его там же кнопкой установки.
