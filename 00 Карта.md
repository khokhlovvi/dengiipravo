Сайт из двух страниц (О нас, Решения) на React + Vite — **опубликован 13.10.2026 на https://dengiipravo.ru**

## Недавно изменённое

```dataview
TABLE WITHOUT ID file.link AS "Заметка", file.folder AS "Раздел", file.mtime AS "Изменена"
WHERE file.name != this.file.name AND file.name != "CLAUDE" AND type != "section" AND type != "roadmap" AND type != "index" AND type != "log"
AND !contains(file.folder, "90 Шаблоны") AND !contains(file.folder, "91 Исходники")
SORT file.mtime DESC
LIMIT 10
```

## Как работать

Открой панель Claude справа и пиши обычным языком: «что дальше по дорожной карте»,
«разбери 91 Исходники и разложи по разделам», «что мы знаем про …», «запиши: …».
Всё важное Claude запишет сюда сам.
