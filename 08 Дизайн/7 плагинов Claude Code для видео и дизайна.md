# 7 плагинов Claude Code для видео и дизайна

## Суть

Рилс блогера Ден.AI ([@den_ai_dev](https://www.instagram.com/reel/DfAAa56I1jL/), 27.10.2026): семь бесплатных плагинов, с которыми Claude Code делает ролики и дизайн без монтажа. Владимир прислал 2026-10-28 для проекта «Деньги и Право» (сайт, презентации, видео). Названия взяты из расшифровки речи, возможны искажения: репозитории сверить перед установкой.

## Подробности

1. Hyper Frames — Claude верстает обычную страницу, из неё получается видео (по словам автора, 70 000+ звёзд на GitHub)
2. Remotion — ролик из React-компонентов: субтитры, карты, рендер; бесплатен для небольших команд (до трёх человек)
3. Скиллы Эмиля Ковальски — анимация интерфейса: тайминги, пружины (то же, что Apple Design и review-animations в [[Design Router — как выбирать дизайн-скиллы]])
4. Taste — против одинаковых нейросетевых лендингов (100 000+ звёзд)
5. Impeccable — 24 команды: типографика, отступы, шрифты, финальная полировка
6. frontend-design — официальный плагин Anthropic: смелая типографика и своя палитра
7. UI/UX Pro Max — 192 палитры и 74 пары шрифтов (140 000+ звёзд)

PDF с командами установки и двумя бонусными плагинами автор раздаёт в Telegram-боте @den_ai_files_bot по слову plugins (воронка в его канал).

## Что из этого нам

- Плагины 3–7 уже есть в материале про Design Router; новое здесь — Hyper Frames и Remotion для видео
- Видео может пригодиться для мероприятия в Грозном и для презентаций ([[13 Мероприятие в Грозном]]), но сначала нужна задача
- Правила проекта важнее любого плагина: без точек в заголовках, без денежных сумм в кейсах, спокойная анимация. Taste и Impeccable вместе не запускать (см. предупреждения в материале про Design Router)
