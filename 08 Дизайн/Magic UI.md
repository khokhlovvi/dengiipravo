# Magic UI

## Суть

Владимир увидел рилс dashi_agent: в Claude Code пишут «Rebuild my landing page with Magi…», и лендинг пересобирается. В подписи — «Бесплатная библиотека Magic UI». Скорее всего, речь о [magicui.design](https://magicui.design). Это бесплатная (MIT) библиотека анимированных блоков для лендингов. К ней есть MCP-сервер, через который Claude Code берёт готовые компоненты. Есть похожий продукт с почти тем же названием — 21st.dev Magic. По обрезанной подписи нельзя понять, какой из двух показан в ролике.

Для нашего сайта Magic UI пока не подходит: он требует Tailwind и shadcn, а сайт написан на чистом CSS. Его эффекты громче, чем «спокойная анимация» из правил проекта, а дизайн уже утверждён. Пригодится для отдельных лендингов и концептов.

## Подробности

**Что это.** Набор анимированных компонентов на React, Tailwind CSS и Motion (бывший framer-motion). Устроен как shadcn/ui: компонент не ставится пакетом, а копируется кодом в проект, и его можно править. Сама библиотека бесплатная. Есть платная Pro: шаблоны и премиум-компоненты, разовая оплата $199 (по официальной странице). Число компонентов официально не указано, сторонние сайты пишут «150+» #уточнить.

**Подключение к Claude Code.**
- Официальный MCP-сервер `@magicuidesign/mcp` ([документация](https://magicui.design/docs/mcp)), ключ API не нужен. Команда установки для Claude Code, судя по README, — `npx @magicuidesign/cli@latest install claude`. Команду не проверяли, перед запуском посмотреть, что она пишет в настройки #уточнить.
- В их репозитории есть и Agent Skill `magic-ui` ([skills.sh](https://skills.sh/magicuidesign)), как его ставить — не проверено.
- Компоненты добавляются через shadcn: `npx shadcn@latest init`, потом `npx shadcn@latest add @magicui/<компонент>`.
- Проверили 13.10.2026: MCP не обязателен. Блоки ставятся напрямую командой `npx shadcn@latest add https://magicui.design/r/<имя>.json`. Установщик тянет лишнее: битый `button.jsx` с пакетом `cn` и next-themes. Их пришлось убирать и править вручную.

**Не путать: 21st.dev Magic** (`@21st-dev/magic`). Он не берёт готовые блоки, а генерирует новые по описанию. Нужен ключ API, описания уходят в сервис 21st.dev, цены не нашли.

**Что есть для лендинга:** Marquee (бегущая строка, например с логотипами партнёров), Bento Grid, Number Ticker (счётчики цифр), Border Beam и Shine Border (подсветка рамок), Dot и Grid Pattern (фоны), Globe, Meteors, анимированный градиентный текст. Из этого списка по официальным примерам проверен только Globe.

**Минусы.**
- Тяжело для телефонов: Motion, canvas и WebGL-фоны (Globe, Particles).
- Неясно, учитывают ли компоненты «уменьшить движение» в системе. Наш сайт это уже делает, и с Magic UI это пришлось бы проверять вручную.
- Шаблонный вид: многие AI-лендинги собраны из тех же блоков и выглядят одинаково.

**Как это ляжет на наш сайт.** Сайт (`91 Исходники/site`) написан на React 19 и Vite 6, стили — обычный CSS, без Tailwind и shadcn. Чтобы взять Magic UI, пришлось бы добавить Tailwind, shadcn и Motion и переписать стили. Это противоречит решению от [[02 Дневник/2026-10-12|12.10.2026]]: дорабатываем утверждённый дизайн, новый не делаем. Если брать — то точечно один спокойный блок (например, бегущую строку партнёров или счётчик), переписав его на наш CSS.

## Черновик главной на Magic UI

Собран [[02 Дневник/2026-10-13|13.10.2026]] для сравнения с сайтом. Тексты и фото взяты с сайта, новых цифр нет. Сайт не тронут.

- Папка проекта: `91 Исходники/site-magicui/`, готовая сборка — в `dist/`. Стек: React 19, Vite 6, Tailwind 4, Motion.
- Посмотреть: открыть `dist` через любой локальный сервер. Двойной щелчок по `index.html` не сработает: браузер не запускает скрипты страницы, открытой как файл.
- Править: `pnpm install` в папке проекта, потом `pnpm dev`. Папку `node_modules` после сборки удалили: в ней 938 служебных `.md`, они засорили бы хранилище.
- Блоки по разделам:
  - первый экран — фон из точек (Dot Pattern), подпись с бликом (Animated Shiny Text), заголовок с проявлением (Blur Fade), кнопка с бегущим бликом (Shimmer Button), фото справа как часть фона;
  - лента решений — две бегущие строки (Marquee): инструменты и правовая работа;
  - «С какими задачами…» — карточки с подсветкой за курсором (Magic Card);
  - принцип — текст проявляется по словам при прокрутке (Text Reveal);
  - «Экспертиза команды» — фото склада слева как часть фона, справа три пункта с иконками;
  - «Наш опыт» — карточки и раскрывающийся список дел;
  - контакты — мерцающая сетка (Flickering Grid) и круги (Ripple) на синем фоне.
- Упрощения черновика: формы заявки нет, кнопки ведут к контактам и в почту; страницы «Решения» нет. Короткие подзаголовки в «Экспертизе» придуманы для пунктов, текст под ними — с сайта.
- Вес: скрипт 421 КБ (у сайта — 224 КБ), то есть почти вдвое больше.
- Фото без рамок ([[02 Дневник/2026-10-13|13.10.2026]], по просьбе Владимира): фото — часть дизайна, а не отдельные карточки. Убрали рамки, скругления, тени и бегущую подсветку (Border Beam). Края фото плавно уходят в белый фон (CSS-маска), фото занимают свою половину блока до края экрана. На телефоне растворяются верх и низ.
- Движение: при «уменьшить движение» в системе бесконечные анимации останавливаются.
