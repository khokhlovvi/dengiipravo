# 23.11.2026

## Главное за день

- Поднят свой VPN на втором сервере AdminVPS по гайду «Свой VPN на VPS через AmneziaVPN». Выданный при заказе IP `81.29.147.194` оказался заблокирован в РФ на уровне провайдеров (таймаут на порт 22 из двух независимых сетей, из-за рубежа доступен); по запросу в поддержку AdminVPS адрес заменили на `194.87.1.155` — доступность из РФ проверена (пинг ~110 мс, SSH открыт). Сервер: Ubuntu 24.04, 2 ГБ памяти, 15 ГБ диска. Защита по гайду сделана сразу: пароль root заменён на длинный случайный (хранится у Владимира, в заметки не пишется), установлен fail2ban (бан на сутки после 5 неудачных попыток; в исключениях домашний IP и внутренние сети Amnezia). Протокол **AmneziaWG** установлен через приложение AmneziaVPN на Маке: контейнер `amnezia-awg2` в работе, наружу смотрит UDP-порт 33394. Дальше по гайду — раздача ключей устройствам через «Поделиться»; если провайдер начнёт резать AmneziaWG, доустановить XRay на тот же сервер.
